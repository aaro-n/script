mode=fulltext中间件用 @jocmp/mercury-parser 算法自动猜正文，常漏段落
itemContent路由用你指定的 CSS 选择器精确从详情页抓取，不丢内容

高级路由参数 (routeParams)

支持格式：key: value 或 key: value (注释)，会自动填充 routeParams 和高级过滤中的所有字段。

✅ 比 mode=fulltext 更精准：你指定正文容器，RSSHub 去 itemLink 页面精确抓取，缓存并清洗（保留 img）。选择器越准，全文越全。

抓取流程（每一步都是 RSSHub 真实代码逻辑）：

  1. 先访问 列表页（你的"目标网页地址"），用 item/itemTitle/itemLink 等选择器提取每篇文章的标题和链接
  2. 得到文章列表后，对每一篇，向它的 itemLink 详情页 发起 HTTP GET 请求
  3. 在详情页 HTML 中，用 cheerio（类似 jQuery）执行 $(itemContent)，取出你指定的正文容器
  4. 用 sanitize-html 清洗 HTML（去除 script/style，保留 img/a/p 等安全标签）
  5. 将清洗后的正文 替换 RSS 条目原有的 description
  6. 结果写入 缓存（cache.tryGet），同一文章 24 小时内不重复抓取

💡 只要 itemLink 指向的页面包含完整正文，配合正确的 itemContent 选择器，就能拿到完整全文。

📖 所有路由通用。正则语法、大小写敏感性等详见 RSSHub 参数文档
